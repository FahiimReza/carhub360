# CarHub360 - Premier Car Platform

## 🚗 Project Overview
CarHub360 is a comprehensive automotive platform for Bangladesh, offering car rentals, sales, services, and community features. Built with React and modern web technologies.

## ✨ Key Features
- **Car Rental & Sales**: Browse 60+ car models with real-time availability
- **3D Car Configurator**: Interactive car customization experience
- **Service Portal**: Professional maintenance and repair services
- **Community Blog**: Share experiences and automotive knowledge
- **Admin Dashboard**: Complete management system with analytics
- **Multi-page Architecture**: Optimized performance and SEO

## 🛠 Technical Specifications
- **Frontend**: React 18, TailwindCSS, Lucide Icons
- **Database**: 3NF normalized structure with localStorage simulation
- **Architecture**: Multi-page Application (MPA) for better performance
- **Charts**: Chart.js for analytics visualization
- **3D**: Three.js for car configurator
- **Maps**: Leaflet for location services

## 📊 Database Schema (3NF)
- **Users**: Authentication and profiles
- **Cars**: Vehicle inventory and specifications  
- **Bookings**: Rental transactions
- **Reviews**: User feedback system
- **Blog**: Community content
- **Services**: Maintenance records
